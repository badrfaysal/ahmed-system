# نظام أحمد - نظام إدارة الأقساط

## المتطلبات
- [XAMPP](https://www.apachefriends.org/) — يشمل PHP 8.2+ و MySQL
- [Composer](https://getcomposer.org/Composer-Setup.exe) — مدير مكتبات PHP

## خطوات التشغيل

### 1. تنزيل الملفات
نزّل المشروع ZIP من الزر الأخضر أعلاه ثم فك الضغط.

### 2. تشغيل ملف الإعداد التلقائي
افتح مجلد المشروع ثم دوس دبل-كليك على ملف:
```
setup.bat
```
هيعمل كل حاجة أوتوماتيك.

### 3. إنشاء قاعدة البيانات
- شغّل XAMPP وافتح phpMyAdmin: `http://localhost/phpmyadmin`
- أنشئ قاعدة بيانات اسمها: **ahmed**
- استورد ملف `.sql` اللي استلمته

### 4. تشغيل النظام
افتح Command Prompt داخل مجلد المشروع وشغّل:
```bash
php artisan serve
```
ثم افتح المتصفح على: **http://localhost:8000**

---
> **ملاحظة:** لو كلمة مرور MySQL عندك مختلفة عن الافتراضي (فارغة)، غيّر `DB_PASSWORD` في ملف `.env`.
